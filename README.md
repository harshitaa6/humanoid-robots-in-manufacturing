# Humanoid Robot Integration into a CNC Manufacturing Cell

## Project Overview

This project investigates how a humanoid robot could be integrated into an existing automated CNC manufacturing cell at Hochschule Harz.

The main focus is humanoid-performed quality inspection, supported by CNC data integration and a digital proof of concept.

## Research Objectives

- Analyse the existing ISEL CNC manufacturing cell.
- Investigate humanoid robot applications in manufacturing.
- Develop a conceptual CNC–ROS 2 integration architecture.
- Demonstrate digital data exchange through a proof of concept.
- Evaluate technical feasibility and safety requirements.

## Project Scope

The project focuses on software integration and a digital proof of concept. Physical humanoid implementation is not currently assumed.

## Repository Structure

- `literature/` – Research papers and literature notes
- `cnc_requirements/` – CNC cell observations and requirements
- `architecture/` – System architecture and diagrams
- `ros2_workspace/` – ROS 2 development files
- `simulation/` – Digital CNC simulation
- `inspection_test_data/` – Sample inspection images and test data
- `database/` – Database design and scripts
- `validation_results/` – Test cases and results
- `safety_analysis/` – Safety assessment and relevant standards
- `final_report/` – Report drafts and documentation
